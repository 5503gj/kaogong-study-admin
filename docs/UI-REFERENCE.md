# 界面优化记录

本次界面调整参考了 GitHub 上的 `frontend-design` 与 `ui-ux-pro-max` 指导，以及 shadcn Dashboard blocks 的布局思路：

- 每个页面保留一个主要任务，减少导航和卡片之间的视觉竞争；
- 桌面端使用常驻侧边导航，移动端保留抽屉导航；
- 继续使用现有 shadcn/Radix 组件，不额外引入大型 UI 框架；
- 使用语义化颜色、统一圆角、间距、阴影和 focus 状态；
- 对 AI 页面扩大主对话区域，对看板保留指标、趋势和行动建议的层级；
- 通过 CSS 背景、渐变和轻量装饰增强层次，不使用与备考场景无关的装饰图片。

这是一套前端设计参考，不代表引入或复制第三方仓库代码。
